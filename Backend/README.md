# ⚡ VoltCart Backend  
**REST API for a Full-Stack E-Commerce Platform**

🛠️ **Live API:** https://voltcart-backend.onrender.com  

---

## 📌 Overview  
The VoltCart backend is a RESTful API built to support a full-stack e-commerce platform for electronic components.  

It handles product management, authentication, cart operations, and order processing, while integrating with external services for image storage. The system is designed to simulate real-world backend architecture with scalable routing, modular controllers, and secure access control.

---

## 🚀 Highlights  
- RESTful API built with Express and Node.js  
- MongoDB database with Mongoose for schema modeling  
- JWT-based authentication and protected routes  
- Cloudinary integration for image storage  
- Modular architecture using controllers, routes, and middleware  

---

## ✨ Key Features  

### 📦 Product Management
- Create products with image upload support  
- Store product data including categories, variants, and pricing  
- Retrieve product listings for frontend display  

### 🔐 Authentication & Authorization
- JWT-based authentication system  
- Secure admin login  
- Middleware-protected routes for admin actions  

### 🛒 Cart & Orders
- Handle cart-related operations  
- Create and store customer orders  
- Retrieve and manage order data  

### ☁️ File Uploads
- Image upload handling using Multer  
- Cloudinary integration for persistent image storage  

### 🌐 API Design
- RESTful route structure  
- JSON-based request/response handling  
- CORS-enabled for frontend communication
